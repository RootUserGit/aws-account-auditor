## audit-frontend

### Finding detail & evidence

- **`EvidenceAutoTables`** (`src/components/EvidenceAutoTables.tsx`): scans `evidence_json` for **top-level keys whose value is a non-empty array of plain objects** and renders **`PaginatedTable`** columns (skips keys handled by bespoke tables, `remediation_playbook`, bare `error` payloads).
- **Finding page** `src/app/dashboard/runs/[runId]/findings/[findingId]/page.tsx`:
  - If **`status === "unknown"`** and **`evidence_json.error`** starts with **`unknown_evaluator:`** — show an **alert** that the worker/rule pack is out of sync and **`audit-worker` must be rebuilt/restarted**; **do not** show the orange remediation strip for that case (remediation does not apply until evaluators match YAML).
  - Renders **`EvidenceAutoTables`** after existing bespoke evidence tables and **before** the collapsible raw JSON block.
  - Raw block title: **“Raw evidence JSON (advanced)”**.

### Dashboard summary (`src/app/dashboard/page.tsx`)

- **Summary cards:** added a fourth card for **`summary.by_status.unknown`** count; helper copy under the cards explaining unknowns (missing data/permissions, empty sample, stale worker / `unknown_evaluator`).
- **By severity (pie):**
  - `label={false}` on **`Pie`** to remove on-slice labels that clipped and produced bad focus outlines.
  - Margins / **`ResponsiveContainer`** **`min-w-0`** so charts don’t overflow the grid.
  - **`DashboardPieSector`** via **`shape`**: hover **outerRadius** bump, **stroke** / **filter** transitions, **`rootTabIndex={-1}`** to reduce stray focus rings.
  - **`Pie`**: **`isAnimationActive="auto"`**, **`animationDuration`** / **`animationEasing`** for calmer first draw.
  - **`Tooltip`**: **`cursor={false}`** on the pie (no polar cursor overlay); **`isAnimationActive={false}`**; **`wrapperStyle={CHART_TOOLTIP_WRAPPER}`** (outline only—**no** `transform` CSS transition on the wrapper).
  - **`ChartCategoryCountTooltip`**: tooltip text **`Medium: 30`** style (category + count), not **`Checks: 30`**; **`min-w` / `min-h` / `tabular-nums`**; when inactive, an **invisible same-size shell** instead of **`null`** so Recharts doesn’t remeasure from zero on every re-enter.
- **By status (bar):**
  - **`YAxis`** width / ticks, margins, **`Bar`** **`maxBarSize`**, **`barCategoryGap`**, **`activeBar={DashboardStatusActiveBar}`** (wider hover rect + stroke + brightness).
  - **`Bar`**: mount **`animationDuration`** / **`ease-out`**.
  - **`Tooltip`**: **`cursor={{ fill: "rgba(148, 163, 184, 0.08)" }}`** for a soft category band; same **`isAnimationActive`**, **`wrapperStyle`**, and **`ChartCategoryCountTooltip`** as the pie.

### Bugs / UX fixes (charts + tooltip)

- **Misleading tooltip name “Checks”** for severity/status → **custom tooltip content** showing **`{Label}: {count}`**.
- **Pie:** removed bad **slice label** / **selection box** interaction; **polar tooltip cursor** disabled.
- **Bar:** reduced odd **grey overlay** / layout issues vs earlier **`activeBar`** defaults.
- **Tooltip “flies from top-left”:**
  - Between slices: addressed by **disabling Recharts tooltip animation** and avoiding misleading wrapper motion.
  - On **re-hover after leaving** the chart: fixed by **removing CSS `transition` on `transform`** for the wrapper (Recharts drops `transform` when inactive; the browser was easing from **translate(0,0)** into place) plus the **always-mounted invisible tooltip shell** for stable **`getBoundingClientRect()`**.

## Operational notes (not code)

- **`unknown_evaluator:…` in evidence:** usually means the **running `audit-worker` image** does not include the **`audit_agents.rules_engine`** evaluators that match the YAML on disk—**rebuild and restart** the worker after pulling new rules.
- **High `unknown` counts** can also come from **missing inventory**, **AccessDenied**, **empty or capped samples**, or **unset** collector fields—not only evaluator mismatch.
